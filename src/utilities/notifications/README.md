# Notification Store

A lightweight, zero-dependency transient notification (toast) system built on a vanilla zustand store. Works in React and non-React code.

## Import

```ts
// Imperative API (React and non-React)
import { notify, dismiss, dismissAll } from 'spfx-toolkit/lib/utilities/notifications';

// React hook
import { useNotifications } from 'spfx-toolkit/lib/utilities/notifications';

// Via utilities barrel
import { notify, useNotifications } from 'spfx-toolkit/lib/utilities';
```

## Imperative API

### `notify(input): string`

Adds a notification and returns its generated id.

```ts
const id = notify({ type: 'success', message: 'Item saved!' });
const id = notify({ type: 'error', message: 'Load failed.' });        // sticky
const id = notify({ type: 'warning', message: 'Check your input.' });
const id = notify({ type: 'info', message: 'Processing...' });
const id = notify({ type: 'info', message: 'Custom 10s', duration: 10000 });
```

**Default durations per type:**

| Type    | Default duration | Behaviour             |
|---------|------------------|-----------------------|
| success | 3000 ms          | auto-dismissed        |
| info    | 3000 ms          | auto-dismissed        |
| warning | 5000 ms          | auto-dismissed        |
| error   | 0                | sticky (manual only)  |

Pass `duration: 0` to make any type sticky; pass a positive number to override.

### `dismiss(id: string): void`

Removes the notification with the given id and cancels its auto-dismiss timer.

```ts
dismiss(id);
```

### `dismissAll(): void`

Removes all active notifications and cancels all pending timers.

```ts
dismissAll();
```

## React Hook

```tsx
import { useNotifications } from 'spfx-toolkit/lib/utilities/notifications';

function MyComponent(): JSX.Element {
  const { notifications, notify, dismiss, dismissAll } = useNotifications();
  // ...
}
```

## Component

The `SPNotificationBar` component renders the active notifications using Fluent UI `MessageBar`s. See `src/components/SPNotificationBar/README.md`.

## Notes

- Notification IDs are generated by a monotonic counter — deterministic and collision-free.
- Auto-dismiss timers call `.unref()` when available so Node.js test runs do not hang.
- The store is module-level; there is one instance per page/bundle.
